II. NEN TANG LY THUYET VA THIET KE COT LOI (THEO LAB2.PDF)
================================================================================

1. Ngan xep (Stack - LIFO):
   - Nguyen tac "Last In, First Out" (Vao sau ra truoc).
   - Cac thao tac chinh:
     + push(E item): Them phan tu vao dinh stack (top).
     + pop(): Lay va xoa phan tu o dinh stack.
     + getPeek(): Lay phan tu o dinh stack nhung khong xoa.
     + isEmpty(): Kiem tra stack co rong hay khong.
     + size(): Tra ve so luong phan tu.
     + contains(E item): Kiem tra phan tu co ton tai khong.
     + print(): In cac phan tu tu dinh xuong day.

2. Hang doi (Queue - FIFO):
   - Nguyen tac "First In, First Out" (Vao truoc ra truoc).
   - Cac thao tac chinh:
     + enQueue(E item): Them phan tu vao cuoi hang doi (rear).
     + deQueue(): Lay va xoa phan tu o dau hang doi (front).
     + getFront(): Lay phan tu dau tien nhung khong xoa.
     + isEmpty(): Kiem tra hang doi co rong hay khong.
     + size(): Tra ve so luong phan tu.
     + contains(E item): Kiem tra phan tu co ton tai khong.
     + print(): In cac phan tu tu front den rear.

3. Lop Node<E>:
   - Don vi luu tru du lieu (element) va lien ket (next).
   - Cung cap cac constructor va getter/setter cho element va next.

2. EXERCISE 2 (Ex2)
- De bai: P(n) = 2^n + n^2 + P(n - 1) voi n > 1; P(1) = 3.
- Cac file: Node.java, StackInterface.java, MyStack.java, Main.java.
- Giai thuat:
  + De quy (recurP): Base case n=1 tra ve 3; buoc de quy cong 2^n + n^2 + recurP(n-1).
  + Khu de quy bang Stack (stackP): Push cac gia tri tu n giam ve 2 vao Stack.
    Khoi tao result = 3. Pop tung phan tu k va cong don (2^k + k^2).
- Lenh chay:
  cd Ex2
  javac *.java
  java Main
- Ket qua in ra cmd:
  n = 1 | De quy: 3 | Stack: 3 | Khop: true
  n = 2 | De quy: 11 | Stack: 11 | Khop: true
  n = 3 | De quy: 28 | Stack: 28 | Khop: true
  n = 4 | De quy: 60 | Stack: 60 | Khop: true
  n = 5 | De quy: 117 | Stack: 117 | Khop: true
  n = 6 | De quy: 217 | Stack: 217 | Khop: true

4. EXERCISE 4 (Ex4)
- De bai: Kiem tra cac loai dau ngoac (), [], {} co can bang khong.
- Cac file: Node.java, StackInterface.java, MyStack.java, Main.java.
- Giai thuat:
  + Gap ngoac mo '(', '[', '{': push vao Stack.
  + Gap ngoac dong ')', ']', '}': pop tu Stack ra kiem tra co dung cap khong. Neu Stack rong hoac khong khop cap -> false.
  + Ket thuc chuoi: neu Stack rong -> true, con phan tu -> false.
- Lenh chay:
  cd Ex4
  javac *.java
  java Main
- Ket qua in ra cmd:
  Bieu thuc: {[()]}
  Can bang: true

  Bieu thuc: {[(])}
  Can bang: false

  Bieu thuc: ((()))
  Can bang: true

  Bieu thuc: ())
  Can bang: false

  Bieu thuc: ([{}])
  Can bang: true

  Bieu thuc: {[}
  Can bang: false

  Bieu thuc: a * (b + c) - [d / {e * f}]
  Can bang: true

  Bieu thuc: a * (b + c) - [d / {e * f)]
  Can bang: false
